## 0.1.0 — 2026-10-26

The project build: harbor-ops becomes a working repository instead of
a test scaffold, without changing a single day-1 record.

- `harbor_ops/` CLI (Python, stdlib only): `board`, `freeze`,
  `oncall`, `status` as read-only views of derived state; `canary`
  show/toggle/reset against a local, gitignored demo file.
- `harbor_ops/derived-state.json`: the fold's snapshot of the 11
  day-1 records, generated by `tools/derive.py`; the CLI reads it.
- `tools/fold.py`: this repo's own copy of the labelled minimal port
  of the fold's derive semantics (provenance in its header).
- Fictional summer/winter timetables; the board's season comes from
  the derived key `schedule.season` (summer by default).
- Test suite: 12 unittest tests, including a consistency test that
  fails if the shipped snapshot differs from a fresh fold of the
  records. CI workflow runs the suite and a CLI smoke test on every
  push and pull request.
- README rebuilt (working example first, then the model, then the
  coordination layer, with the fold diagram in `docs/`), MIT LICENSE,
  this changelog.
